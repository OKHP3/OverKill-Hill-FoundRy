## Decisions and rationale

1. Keep the Logic, Tone, and Structure triad as the default conceptual basis. It covers the three quality tensions repeatedly identified in the source without requiring a large fixed chain.
2. Treat Path 4 as a synthesis layer, not as proof of consensus. A synthesis may be coherent while still being wrong or incomplete.
3. Make AntiPath-R conditional. Always-on dissent adds cost and can create artificial disagreement; targeted dissent is proposed for clean convergence, high stakes, ambiguity, or explicit request.
4. Use a catalog plus runtime loadouts instead of running every agent on every prompt. This is proposed as the token-economy control.
5. Place deployable behavior in the mandatory ledgers rather than in development-only processing or ideation files. This follows the user’s stated read-only constraint and keeps the proposed published package compact.
6. Keep hydration as a schema skeleton rather than assuming that a GPT or Project can write back to its attached files. Replay requires an explicit export and re-entry workflow, which remains to be implemented and tested.
7. Treat Aurifexo-R as a substrate beneath phase tools. This preserves its cross-cutting role and avoids forcing a foundational logic layer into a single lifecycle phase.

1. Analyze intent, constraints, ambiguity, and task risk.
2. Select a small loadout from the agent catalog, using AgentZero-R when enabled.
