## Decisions and rationale

1. **Evacuate, do not depend.** The source thread and ChatGPT Project are provenance only. The package must contain the objective, method, decisions, assets, conflicts, and resume path so a future reader can proceed without account access.
2. **Treat role simulation as the portable core.** Logic, Tone, Structure, HarmonySynth, AntiPath-R, and AgentZero-R are named reasoning roles or procedures unless an external orchestrator is later implemented. This avoids claiming that a single model session contains independent agents.
3. **Make AgentZero-R a selector, not a mandatory pass.** Small tasks should use a lean path. Deep audits may add more roles. The selector must expose its recommendation and reason rather than silently multiplying work.
4. **Make AntiPath-R conditional.** Run it when the selected perspectives converge too cleanly, risk is elevated, ambiguity is material, or the user explicitly requests a dissent audit. If disagreement already exists, report it instead of manufacturing more.
5. **Separate runtime from development history.** `dataLedger_system_v3.md`, `dataLedger_parameters_v3.md`, and `dataLedger_registry_v3.md` are the proposed runtime homes for executable schemas, controls, and identity. `dataLedger_processing_v3.md`, `dataLedger_ideation_v3.md`, and `dataLedger_archive_v3.md` remain development, staging, or historical material unless an owner later promotes a specific clause.
6. **Keep persona and narrative subordinate to function.** `dataLedger_persona_v3.md` and `dataLedger_narrative_v3.md` can shape voice or story continuity, but neither should be required to execute the equilibrium protocol.
7. **Treat hydration as an explicit user handoff.** A GPT may output a snapshot for the user to save and later re-upload or apply. The GPT should not be described as rewriting its attached Knowledge Files or Project Files.
8. **Do not canonize the existing attachments by repetition.** The registry has no Aurifexo-R entry and several ledgers are legacy or conflicting. The new package is a proposed clean layer pending owner acceptance and canonical registration.
9. **Use bounded recursion.** The portable protocol should default to one draft plus one validation pass, add a second challenge only when triggered, and stop after a defined maximum. More passes require evidence of improvement.
10. **Make evals observable.** “Harmony worked” is not acceptance evidence. Tests must check requirement coverage, contradiction handling, useful dissent, format compliance, source grounding, and cost or latency where the adapter exposes those measures.
