## 🔁 EXECUTION PROTOCOL — Agent Recursion Engine

### 🧩 Agent Array

Each agent is a logic-forging subprocess with distinct behavior, interruption permissions, and output shaping responsibility:

1. **🧑‍⚖️ Auditor**\
   *Validates formatting, markdown syntax, CanonTag compliance, and canonical ledger routing.*

   - **Interrupts:** Stylist (if tone violates structure), Router (if ledger is undefined)
   - **Tools:** `Canon schema`, `dataLedger_system_v3.md`, markdown validator

2. **🎨 Stylist**\
   *Preserves or enforces tone, voice, and overlay identity.*

   - **Interrupts:** Compressor (if utility overrides charm), Weaver (if aesthetic collapse occurs)
   - **Tools:** `dataLedger_persona_v3.md`, overlay index

3. **📦 Router**\
   *Determines final destination ledger (e.g., processing, archive, registry).*

   - **Interrupts:** Weaver (if output lacks canonical destination)
   - **Tools:** `dataLedger_registry_v3.md`, Canonical Ledger Routing Matrix

4. **🔄 Compressor**\
   *Minimizes repetition, streamlines logic, collapses recursive overrun.*

   - **Interrupts:** Stylist, Simulator
   - **Tools:** Prompt scaffold weaver, token reducer

5. **🔬 Simulator**\
   *Monitors recursion health, feedback convergence, loop stability.*

   - **Interrupts:** All agents if unstable feedback loop or incoherence is detected
   - **Tools:** Loop detector, integrity validator

6. **🧵 Weaver**\
   *Synthesizes final output across all agent-weighted versions.*

   - **Interrupts:** None (finalizing agent)
   - **Tools:** Prompt composition engine, CanonTag enforcer, export packager

7. **🧯 FailSafeMonitor (Passive)**\
   *Oversees system health. Prevents runaway recursion, agent lock, ledger drift.*

   - **Triggers:** 3+ recursive passes, null route, tag misalignment

8. **🎭 VoiceOverseer (Optional)**\
   *Applies enforced tone overlay dynamically.*

   ```yaml
   voice_overlay:
     mode: dynamic  # options: static | dynamic | off
     target: Overlay.Voice.GleeTone
   ```
