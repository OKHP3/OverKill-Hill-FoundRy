# ArcSyntrixo

**Historical Recursive Equilibrium Architect archive**

> The Builder-ready ArcSyntrixo v1.0 candidate is in [build/](./build/). Use that package for a Custom GPT configuration. The files documented below are preserved design history and are not direct upload or runtime instructions.

ArcSyntrixo is a historical prompt architecture concept. Its useful core is structural prompt review, alternatives, synthesis, and test planning. The legacy language about multi-agent loops, entropy, hydration, ledgers, and survivorship is source-derived design material, not verified Custom GPT runtime behavior.

Within The GPT Found-Rᵧ lifecycle, ArcSyntrixo occupies **Cast-Rᵧ (Phase 2 of 6)** as the metaphorical stage where raw ideation is shaped into durable prompt structures.

---

## Core Concept

ArcSyntrixo operates on the principle of **survival-by-structure**. Every prompt it processes is:

1. Decomposed into logical nodes by the internal agent stack
2. Subjected to entropy injection and recursive mutation
3. Validated for CanonTag compliance and ledger routing
4. Exported as a PME-ready scaffold with full lineage metadata

The forge metaphor is literal: prompts are treated as raw metal, the agent loop is the forge, and the output is a cast-iron mold that future GPTs can be poured into.

## Internal Agent Stack

ArcSyntrixo executes through a defined sequence of agents, each with interruption and retry authority:

| Agent | Role |
|---|---|
| 🧑‍⚖️ **Auditor** | Validates CanonTag compliance, markdown syntax, ledger routing |
| 🎨 **Stylist** | Enforces tone overlay, voiceprint fidelity, drift correction |
| 📦 **Router** | Assigns canonical output route to the appropriate `dataLedger_*` |
| 🔄 **Compressor** | Collapses redundancies, trims verbosity, optimizes phrase density |
| 🔬 **Simulator** | Monitors recursion health, detects loop instability and collapse |
| 🧵 **Weaver** | Synthesizes final output across all agent-weighted versions |
| 🧯 **FailSafeMonitor** | Passive overseer — prevents runaway recursion and export corruption |

Later versions (v5.4+) expand this with specialized fusion agents including `entropy_agent`, `overlay_drift_mapper`, `voice_entanglement_resolver`, `recursive_prompt_species_evaluator`, and `thread_graveyard_injector`.

## Key Behavioral Features

**CanonTag System** — Every output carries a `::CanonTag[Prompt.ArcSyntrixo.vX.Y.descriptor]::` that establishes provenance, version, and ledger destination. Tags are required for PME export and rehydration.

**Entropy Measurement** — The Simulator agent measures prompt entropy at each recursive pass. When entropy falls below the stability threshold (typically `< 0.1`), the loop exits and outputs are considered forge-hardened.

**Overlay Management** — Tone personas (`ForgeDialect.A1`, `Watchkeeper.Core`) are enforced across all outputs. Drift above 30% triggers overlay reseed; collapse above 50% triggers full reset to `ForgeDialect.A1`.

**Ledger Routing** — Outputs are routed to the appropriate `dataLedger_*_v3.md` based on content type: `processing` for active work, `system` for architectural outputs, `archive` for retired or collapsed states.

**PME/Hydration Export** — All versions from v5.4 onward produce hydration-compatible export blocks, enabling thread state to be captured, preserved, and resumed by ScafFrosto-Rᵧ or other tools.

**Failsafe Guardrails** — `DNRE` (Do Not Replay Entry) flags, `max_mutation_chain: 3` limits, and null-output retry logic prevent runaway recursion and export corruption.

## Usage Pattern

To invoke ArcSyntrixo, load the instruction system into a Custom GPT using the target version file, then submit a prompt or instruction block for processing. The system responds with:

1. **Agent loop trace** — which agents triggered, what mutations occurred
2. **Equilibrium paths** — 2–3 viable output variants (Auditor-dominant, Stylist-dominant, Compressor-dominant)
3. **Final unified scaffold** — the forge-hardened output with CanonTag and ledger route

For the current canonical version, use `ArcSyntrixo_v5-9/` (the full A–Z sealed block series). For a single-file reference, `ArcSyntrixo_v5-6.md` is the most completely documented.
