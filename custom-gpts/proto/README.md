# OverKill Hill Proto-GPTs

This directory is the normalized repository home for OverKill Hill proto-GPT materials: preserved prompt packages, historical thread recovery, research, and existing artifacts.

Each direct child uses lowercase ASCII kebab-case and has a root `README.md`. The artifacts are historical evidence unless the child README explicitly identifies a current source of truth.
