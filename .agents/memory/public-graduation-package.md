---
name: Public graduation package
description: ReFolDec public candidates are mixed release shelves with explicit owner approval and deployment gates.
---

The public ReFolDec candidate is a review shelf, not a publication event. It
must name a separately owned target, retain a pending/approved decision, keep
deployment disabled, and include both human review records and an unseen
holdout.

**Why:** Structural validation cannot establish privacy, licensing, usability,
or behavioral performance, and the FoundRy relay must not be implied to be
public merely because a capability has a candidate package.

**How to apply:** Keep support files (specification, provenance, evaluations,
reviews, and release controls) distinct from artifact documents in validators,
and require an explicit owner decision before any deployment workflow is run.
