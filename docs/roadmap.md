# ReFolDec Roadmap

**Relationship to this repository:** ReFolDec is a capability hosted by the private OverKill Hill FoundRy relay. This roadmap plans the capability and any future public artifact; it does not change the FoundRy repository’s identity or visibility.

## v0.1 — FoundRy-hosted capability scaffold

- Declare the FoundRy relay as the repository’s primary identity and ReFolDec as a hosted capability.
- Add documentation for the private capture, private development, and future public-release boundary.
- Add initial specification, vocabulary, example, manifest, and schema.
- Keep public-release materials independent of private Notion URLs and private FoundRy sources.

## v0.2 — Artifact model

- Stabilize artifact maturity states.
- Finalize JSON Schema for ReFolDec artifacts.
- Add example transformations for fiction, nonfiction, process documentation, and Agent Skills.
- Add diagrams for fold/unfold/refold loops.

## v0.3 — Process-capture pipeline

- Add templates for process-capture sessions.
- Add examples showing raw meeting notes folded into process documentation.
- Add xPMN/BPMN-for-Mermaid integration notes.
- Add validator script for artifact front matter.

## v0.4 — Agent Skill packaging

- Add `.agents/skills/refoldec-operator/SKILL.md`.
- Add skill references for folding, unfolding, and refolding artifacts.
- Add tests and fixtures for agent-generated transformations.

## v1.0 — Canonical public release

- Stable naming and positioning.
- Complete examples.
- Published diagrams.
- Usable schemas.
- Public site/project page integration on a separately approved release surface.
