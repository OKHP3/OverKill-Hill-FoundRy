# Private Workshop, Public Artifact

ReFolDec distinguishes between the place where ideas are worked and the place where artifacts are published.

## Private workshop

The private workshop can contain half-formed ideas, speculative connections, scratch notes, incomplete diagrams, and contradictory naming options.

## Public artifact

The public artifact should contain the distilled, named, useful version of that work.

## Working principle

Do not publish the whole workshop. Publish the reusable artifact that survived the workshop.
