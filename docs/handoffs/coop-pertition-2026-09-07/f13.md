# F13 — Executable evidence record prototype

Implemented a pure validator in `artifacts/mockup-sandbox/src/lib/coop-result.ts` with adjacent tests.

The record requires a lowercase SHA-256 digest, non-empty environment and command text, one of `pass`, `fail`, `inconclusive`, or `not-run`, a canonical UTC ISO timestamp, and a non-empty evidence reference. Unknown or missing fields are rejected.

The validator checks syntax only. It does not execute commands, read evidence references, authenticate digests, or interpret evidence prose. A returned `pass` remains a caller assertion and carries the explicit boundary: `caller-supplied; syntax-validated only; independently unverified`. Therefore this prototype provides no independent verified-behavior claim.
