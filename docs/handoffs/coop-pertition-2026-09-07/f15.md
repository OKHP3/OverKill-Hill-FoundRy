# F15 handoff — project revision diff prototype

## Scope and base

Implemented on branch `coop/f15` from the assigned isolated worktree and the
dispatch baseline recorded in the coordinator README. The only writable paths
were the standalone diff module, its adjacent tests, and this handoff.

## Contract

`diffCapabilityProjects(before, after)` compares two current `CapabilityProject`
values without rendering, parsing, executing, or storing their contents. The
result has `authored` and `metadata` arrays of `{ field, before, after }` entries.
Authored fields are the current project fields other than `id`, `createdAt`, and
`updatedAt`; those three are metadata. Entries use the fixed interface field
order, and unchanged values are omitted. Values are retained as data, including
Unicode, null characters, markup-looking text, and other strings.

## Evidence

`coop-project-diff.test.ts` covers identical projects, edited authored and
metadata fields, Unicode and hostile-looking text, deterministic ordering, and
input nonmutation. The prototype has no UI, store, dependency, or source
integration.

## Validation

Focused tests and the repository governance check were run before handoff; exact
commands and outcomes are recorded by the coordinator from the local commit.
