## Coverage

`coop-zip.test.ts` adds an independent stored-ZIP reader and checks:

- UTF-8 flag, Unicode project content, exact entry bytes, and independently calculated CRC values;
- entry ordering and complete generated file coverage;
- empty project fields without truncated entries;
- hostile project names remain data and cannot become absolute, backslash, or parent-traversal archive paths.

The existing generator emits deliberate non-empty document files even when optional project fields are empty; the regression records that behavior rather than inventing an empty generated entry.
