# F12 handoff — structured contract parser prototype

Status: candidate complete; experimental and standalone.

Implemented `parseContract(input, schema)` in `artifacts/mockup-sandbox/src/lib/coop-contract.ts`. The parser accepts a JSON object with an integer `version`, validates that version against the supplied schema, rejects unknown and duplicate fields, checks declared primitive types (`string`, `number`, `boolean`, `null`), and reports required-field and other validation failures with JSON-style paths. Malformed JSON is also reported at `$`.

The adjacent `coop-contract.test.ts` covers a valid contract, missing required data, type mismatch, unknown field/version, duplicate keys, and malformed JSON. This is a pure prototype: no UI, store, configuration, lockfile, or existing project migration is included. Tests demonstrate parser behavior only; they do not establish production readiness or adoption by existing projects.

Validation run from this worktree:

```text
node --experimental-strip-types --test artifacts/mockup-sandbox/src/lib/coop-contract.test.ts
python3 scripts/governance-check.py
```
