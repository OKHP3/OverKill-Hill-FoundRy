# F08 — Evidence wording regression

## Scope

Added `artifacts/mockup-sandbox/src/lib/coop-evidence.test.ts` only. The tests exercise all four generated package kinds (`prompt`, `skill`, `workflow`, and `software`) across complete, reviewed, empty, and whitespace-only evidence states.

## Evidence

- Reviewed projects retain authored evidence while remaining `owner-reviewed-structural-draft`.
- Empty and whitespace-only evidence remain `incomplete-structural-draft`, including when `reviewed` is true.
- Recorded evidence can move a complete project to `ready-for-owner-review-structural-draft`, but generated validation output continues to say behavioral validation is not claimed and publication authorization is not granted.
- Generated `capability.json` and `docs/validation.md` are checked for the separation between authored evidence, behavioral proof, and publication permission.
