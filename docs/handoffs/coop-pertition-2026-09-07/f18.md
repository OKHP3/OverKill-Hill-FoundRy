# F18 handoff — Skillz reference parser prototype

## Scope

Implemented a standalone parser in `artifacts/mockup-sandbox/src/lib/coop-skill-reference.ts` and adjacent unit tests. It accepts only explicit HTTPS `github.com/OKHP3/skillz/blob/<revision>/<path>` references, preserves the original source text, and reports whether the revision is pinned to a complete 40-character commit SHA or remains mutable.

The parser does not fetch references, copy catalog data, add dependencies, or integrate with the UI or core workbench.

## Validation

- Focused tests: `node --experimental-strip-types --test artifacts/mockup-sandbox/src/lib/coop-skill-reference.test.ts`
- Governance: `python3 scripts/governance-check.py`

## Evidence and limitations

The tests cover pinned and unpinned references, malformed URLs, other hosts/repositories, ports, query strings, traversal segments, and credential-bearing URLs. This is a pure parsing prototype; it does not establish that a referenced path exists or that a commit is reachable.
