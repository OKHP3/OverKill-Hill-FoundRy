# F16 handoff — safe import merge planner

Base: `29d3e1abbb833034c083a82922bbe23a8191eb2f` (dispatch baseline; branch was inspected before editing).

Scope is limited to `coop-import-plan.ts`, its adjacent deterministic test, and this handoff. The module accepts two caller-validated version 1 `CapabilityWorkspace` values and produces a pure dry-run preview. It classifies project IDs as `identical`, `conflicting`, or `new`, reports the resulting count and `countOverflow`, clones preview data, and leaves conflict resolution to the caller. It performs no parsing, storage access, writes, overwrite, or UI integration.

Validation: `node --experimental-strip-types --test src/lib/coop-import-plan.test.ts` from `artifacts/mockup-sandbox`.

This is an experimental standalone candidate. The caller-trusted-input contract and lack of runtime wiring mean it is not an import feature or publication claim.
