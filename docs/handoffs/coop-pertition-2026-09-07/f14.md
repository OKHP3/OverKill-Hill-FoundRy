# F14 handoff — package fingerprint prototype

Branch: `coop/f14`  
Base: `29d3e1abbb833034c083a82922bbe23a8191eb2f`  
Scope: `artifacts/mockup-sandbox/src/lib/coop-fingerprint.ts`, its adjacent test, and this handoff.

The prototype exports `fingerprintFiles`, an async SHA-256 digest over file path/content pairs. It sorts paths by UTF-8 bytes, rejects duplicate paths, and frames the file count, path byte lengths, path bytes, content byte lengths, and content bytes using fixed-width big-endian lengths. This keeps Unicode and delimiter-like data unambiguous. It has no UI, storage, network, dependency, or generated-package integration.

Validation: `node --experimental-strip-types --test artifacts/mockup-sandbox/src/lib/coop-fingerprint.test.ts`; `python3 scripts/governance-check.py`.
