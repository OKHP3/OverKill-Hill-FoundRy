# The Process of Process-Capture

ReFolDec exists to name and operationalize a recurring pattern: the act of capturing a process, then capturing the process by which that capture occurred.

This is the recursive layer underneath several OKHP³ efforts.

---

## Core claim

A process is not fully captured when it is merely described.

A process is captured when its context, sequence, assumptions, actors, decisions, artifacts, constraints, and reuse paths are made durable enough to be revisited, revised, visualized, automated, or delegated.

## Why this matters

Thinking has value only when it can be recovered, tested, improved, and applied.

ReFolDec turns epiphany into infrastructure by making the transformation path explicit:

- raw thought becomes a note;
- notes become concepts;
- concepts become processes;
- processes become documents;
- documents become diagrams;
- diagrams become navigation surfaces;
- repeatable actions become Agent Skills;
- mature artifacts become source material for the next cycle.

## Relationship to MPS and BAC

**Magnus Progenitor Saga** is the narrative proving ground.

**Biases as Constants: Vault Codices** is the nonfiction audit ledger.

**ReFolDec** is the transformation codec underneath both.

MPS tests recursion as story. BAC documents recursion as method. ReFolDec packages recursion as a reusable operating model.

---

## Relationship to BPMN / xPMN

BPMN for Mermaid began as a visual notation gap.

The larger problem is not only diagramming. It is capturing the details that make the diagram meaningful, then linking each visual symbol back to the source context that explains it.

ReFolDec treats diagrams as views over captured process knowledge, not as standalone artifacts.

---

## Relationship to Agent Skills

An Agent Skill is a process fossil made executable.

It captures what a human knows how to do, what tools the agent should use, what constraints apply, and how the task should be completed. ReFolDec provides a way to fold process knowledge into skills and unfold existing skills back into their assumptions and reusable primitives.

## Executable capture handoff

The repeatable capture workflow is defined in
`docs/refoldec-capture-pipeline.md`, with its record contract in
`schemas/refoldec-process-capture-schema.json` and a starter template in
`templates/refoldec-capture-record.yaml`. The record is not reusable or
publication-ready until the subject-matter confirmation gate is complete.
Unknown, ambiguous, and rejected material remains visible for recovery.
