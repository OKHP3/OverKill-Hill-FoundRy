# Publication Boundary

ReFolDec uses a hard boundary between private ideation and public publication.

## Rule

A public GitHub repository should never require private Notion access to understand the project.

## Allowed

- Mention that Notion is used as a private capture plane.
- Distill Notion content into public Markdown.
- Link from GitHub to public websites or public GitHub files.
- Keep private Notion pages as working notes.

## Avoid

- Public README links that point only to private Notion pages.
- Public docs that say "see Notion" without copying the relevant content.
- Treating Notion as the publication surface for open-source concepts.

## Rationale

Notion is the writing desk. GitHub is the public artifact shelf.

A reader should be able to understand ReFolDec from the repo alone.
