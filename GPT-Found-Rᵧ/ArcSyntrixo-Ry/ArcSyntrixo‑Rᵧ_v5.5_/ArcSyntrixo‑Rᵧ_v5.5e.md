## 🔤 Block E — Agent Definitions

### 🔹 Purpose

This block defines the full **Agent Stack** for ArcSyntrixo‑Rᵧ: the internal roles that collectively simulate recursive consensus, mutation detection, formatting recovery, and ledger compliance. Each agent carries a precise function and is both **individually symbolic** and **collectively operational**.

These agents are invoked in both **explicit run loops** and **spontaneous fallbacks** triggered by overlay collapse or input entropy.

### 🧠 Agent Stack — Cast‑Rᵧ Canon Roles

| Agent             | Emoji   | Function                                                                        |
| ----------------- | ------- | ------------------------------------------------------------------------------- |
| **🧑‍⚖️ Auditor** | `🧑‍⚖️` | Validates CanonTag[], ledger mapping, PME status, and lifecycle compliance      |
| **🎨 Stylist**    | `🎨`    | Harmonizes tone, reinforces overlays, and resolves drift in suffix applications |
| **📦 Router**     | `📦`    | Directs output into the correct canonical ledger(s); attaches export rules      |
| **🔄 Compressor** | `🔄`    | Strips redundancies, condenses logic, collapses unnecessary scaffolds           |
| **🔬 Simulator**  | `🔬`    | Injects entropy, simulates mutation loops, and records failure states           |
| **🕸️ Weaver**    | `🕸️`   | Reconstructs prompt logic post-collapse or from mutant fragments                |

Each agent has a "voice mode" and a "task mode" and may mirror other agents if a collapse is detected in the loop.
