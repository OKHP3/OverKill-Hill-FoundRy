# Example: Raw Thought to Structured Artifact

This example shows a ReFolDec fold/unfold/refold cycle.

---

## 1. Raw thought

> The recent work on MPS, BAC, xME/xIE, BPMN for Mermaid, Notion, GitHub, and Agent Skills is not a pile of disconnected projects. It is all about capturing the process of process-capture.

---

## 2. Fold: captured note

The projects form a recursive system:

- MPS supplies the narrative proving ground.
- BAC supplies the nonfiction audit ledger.
- xME/xIE supplies the transformation mechanic.
- BPMN/xPMN supplies process notation.
- Agent Skills supply executable packaging.
- Notion captures private thinking.
- A separately approved public ReFolDec surface publishes canonical artifacts after FoundRy graduation.

---

## 3. Fold: structured concept

ReFolDec is the parent framework that explains the movement between these layers.

It folds raw thought into structured artifacts and unfolds mature artifacts into primitives that can be reused.

---

## 4. Fold: release-ready artifact

The concept becomes a FoundRy-hosted release package with:

- README;
- specification;
- operating model;
- vocabulary;
- schema;
- examples;
- roadmap;
- future Agent Skill.

After approval, the package can be published through a separate public ReFolDec artifact surface.

---

## 5. Unfold: reusable primitives

From the mature artifact, extract reusable primitives:

- capture plane;
- canonical plane;
- maturity ladder;
- fold operation;
- unfold operation;
- refold operation;
- process-capture loop;
- public/private boundary rule.

---

## 6. Refold: next artifact

Those primitives can become:

- a Notion dashboard;
- an Agent Skill;
- a process diagram;
- a schema;
- a workshop method;
- a site page;
- a reusable repo template.
