# JSON Contract Inspector example

This example is generated by the existing FoundRy software starter generator. It is a small, dependency-free browser starter that parses JSON and reports the top-level shape. It is not a bespoke business tool and does not claim to validate a domain contract.

Run the repeatable check from the repository root:

```bash
node --experimental-strip-types examples/workbench/software-example/generate.mjs
node examples/workbench/software-example/smoke-check.mjs
```

The generated package is in `generated/`. `generated/backup.json` is an importable version 1 workspace backup. The smoke checker runs the generated `app/index.html` in a real headless Chromium runtime and covers valid JSON, malformed JSON, and hostile text treated as data.

Manual browser check: open `generated/app/index.html`, enter an object, array, primitive, or malformed JSON, and choose **Inspect contract**. A manual browser check is separate from the automated smoke evidence.
