# Repository handoff

Prepare a concise, evidence-backed handoff for a repository task between agents.

This is an OverKill Hill FoundRy source package for a skill capability. It is a reviewable structural draft, not proof of behavior or permission to publish.

## Audience

OverKill Hill maintainers and collaborating agents

## Inputs

Repository status, task scope, exact files, validation results, and known limits.

## Outputs

A Markdown handoff that states the base, owned scope, changes, checks, risks, and continuation point.

## Acceptance

A handoff names the task, base, owner, changed paths, validation commands and outcomes, and remaining limits. A non-handoff request is explicitly a non-trigger.
