# Repository handoff

## Trigger

Use this skill only for the OverKill Hill audience when the request matches the purpose stated below.

## Purpose

Prepare a concise, evidence-backed handoff for a repository task between agents.

## Scope and constraints

Keep private material out of the handoff; preserve exact paths and commit identifiers; never imply approval, publication, or model execution.

## Instructions

When the request concerns handing work to another agent, collect the current branch and base commit, state the exclusive file scope, record changes and meaningful checks, distinguish confirmed evidence from inference, and list limits or open questions. When the request is unrelated to repository handoff, do not activate this skill.

## Acceptance criteria

A handoff names the task, base, owner, changed paths, validation commands and outcomes, and remaining limits. A non-handoff request is explicitly a non-trigger.
